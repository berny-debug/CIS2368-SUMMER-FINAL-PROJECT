# CIS2368 Summer Final Project

This repository contains a Flask-based backend and an EJS-based frontend for managing floors, rooms, and residents.

## Backend
- Flask REST API
- CRUD endpoints for floors, rooms, and residents
- Login endpoint for basic authentication

## Frontend
- EJS templates for login and management pages
- Separate pages for floors, rooms, and residents
- Communicates with the backend via HTTP requests

## Run locally
1. Start the backend:
   - py -3 app.py
2. Start the frontend:
   - cd frontend
   - npm.cmd install
   - npm.cmd start
3. Open http://127.0.0.1:3000
